# Approved Schnorr and Taproot API — 2026-10-12

After the basic verification in record 77, the user requested complete
implementation and documentation following the existing Java Card structure and
style, with joint acceptance afterward. The user explicitly approved this API:

- Existing `0x41 Sign` accepts `cipher: 'schnorr'`, exactly 32 bytes of `digest`,
  and returns the existing `{signature}` map with a 64-byte BIP340 signature.
  Without `taproot`, the key is used directly for BIP340 signing.
- Both Sign and `0x40 ViewKey` accept optional `taproot: {}` for a BIP86
  no-script-tree adjustment, or `taproot: {merkleRoot: byte[32]}` for an adjustment
  committing to the supplied script tree.
- ViewKey with `taproot` returns the adjusted 32-byte x-only public key. A derived
  item also returns its original BIP32 node's chain code. Existing calls without
  `taproot` keep their existing public-key representation and behavior.
- `secp256k1` capability ciphers gain `schnorr` under the existing curve entry.
  Command numbers, Safe item types and other signing requests remain unchanged.

The approved scope is Monoid Java Card, including tests and related documents.
No Monoid mobile APP changes or publication were requested.
