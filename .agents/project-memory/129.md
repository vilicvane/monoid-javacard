## 已撤回的实现

[agent] Monoid 在事务前准备持久 PIN 副本与跨 Applet 的 global 输入，外层事务涵盖 Safe 的 OwnerPIN/状态、Monoid 的持久 PIN 副本，以及首次设置时的 Access PIN/状态。Safe 的 PIN 更新和 Monoid 的内部 Access PIN 更新仅在没有外层事务时自行开启并提交事务，否则加入调用方事务。每个方法只提交或主动撤销自己开启的事务。

现有 APDU/CBOR 与 Safe SIO 方法签名保持不变。Safe.updatePIN 的 Monoid 包装器接收调用方已准备的 global 缓冲，避免事务中再次分配对象。Safe 的会话授权是 transient 状态，更新时撤销授权不随持久事务回滚；失败后需要重新认证。
