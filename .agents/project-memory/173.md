# Java Card 开发中的博客兴趣点记录

## 用户要求

[user] 在 Java Card 开发过程中，记录有意思或有价值的问题、可供展开的兴趣角度和关键事实，方便之后写博客。

[user] 通过 Project Memory 建立项目技能，不使用 Skill Creator。

## 记录方式

[agent] 技能保存在 `skill-javacard-blog/SKILL.md`，通过 `../skills/project-memory-javacard-blog` 符号链接发现。`records.md` 及其链接的数字记录仍是权威来源。

[agent] 在已有相关数字记录中增加 `## 博客兴趣点`，并在 `records.md` 的对应索引行增加 `[blog]`。后续发现更新同一主题，避免为博客线索重复保存研究内容；没有合适主题时再按 Project Memory 新建数字记录。

[agent] 每个兴趣点简要记录切入问题、关键事实、适用边界和参考。区分规范、源码推导、模拟器、实卡观察与尚未验证的假设；采用项目已确认的实卡行为基线，同时保留实际覆盖的卡片、运行时、负载及测量边界，不把项目基线误写成规范保证。核心证据和结论保留在数字记录中，忽略目录中的研究产物只作为补充引用。

[agent] 这是一项开发过程中的记录工作流，不自动撰写或发布博客，也不为了填充笔记而偏离当前任务开展额外研究。记录172中的复位与回收实验是首个关联主题，其具体事实保留在172中。
