All boundaries coincide with needing one more 256B request chunk. Seed also
needs seed-to-master conversion; master skips it. These numbers describe this
card, metadata and retained state, not a universal API maximum or all possible
earlier response sizes. The whole-request protocol ceiling remains 8192B.

109 probes: 71 signatures succeeded and matched/verified against independent
Node/OpenSSL signatures, including negative verification with changed messages;
38 failed with CBOR INTERNAL and SW9000. Each failure was followed by a valid
150B signature without reset or re-authentication. Exact maximum and plus-one
were repeated twice and checked with Message first in CBOR as well as last.
Failure statuses alone do not expose the underlying SystemException reason.
Times include complete Sign APDU transport, derivation and signing, excluding
authentication, setup and memory queries.

Post-success idle RAM is 2256B normally, 1904B after the 600B response. Both
seed/master 1167B Messages fail in the latter state despite passing normally.
The response writer retains expanded capacity after erasure; this is a real
operation-history dependency. Failed normal probes and post-large-response
seed probes temporarily report 96B more idle memory, consistent with the old
expanded key being released before the new key allocation completes. Small
recovery signatures restore the normal retained-key state before the next
probe. Do not use these idle samples as peak-memory measurements.
