- Record 107's earlier Key draft is { index, derivation?: { type: 'hd', curve, path } | { type: 'context', context } }. The user then emphasized concept relationships: secp256k1 does not imply BIP32; BIP32 uses that curve, and SLIP-0010 also supports it. A per-curve profile can be an API restriction but is not conceptual equivalence. No final type, seed-label removal or context profile is approved or implemented.
