## GP 工具的实际行为

本机 GP 24.10.15 的 `--install-only` 会解析参数后直接返回成功，却不执行 `installAndMakeSelectable`；首次迁移实例 SELECT 返回 6A82，注册表也确认实例不存在，尚未发送任何解密请求。通过本机字节码定位此原因后改为 `--create <instance> --package <package> --applet <module>`；该入口实际发送 INSTALL。部署以注册表结果复核，不能仅看工具退出码。空操作的日志单独保留，随后实例创建和卸载均实卡通过。
