## 博客兴趣点

- **切入问题**：同样是改字段，为什么有的备份只需改名，有的必须在卡内重新加密？
- **关键事实**：key/metadata 的外层名称不进入条目二进制认证上下文，原字节可直接映射；Bundle flags/count 纳入 HPKE info 后，简单改包会使认证失败。本次独立模拟器及三张实卡走通两卡批准、独立桥卡内转换，root 未经过主机明文。
- **适用边界**：旧卡须具备兼容的 Extend/Approve，目标接受当前 peer Join；这是一次性迁移工具，不给正式固件增加旧协议分支，也不表示任意历史格式都兼容。存储余量需包括临时 CAP，本轮实测 LOAD 受遗留代码包占用影响。
- **参考**：记录182/187/190，本记录第一张目标卡的验证结果；条目协议见 `doc/item-transfer.md`，Bundle 见 `doc/bundle.md`。
